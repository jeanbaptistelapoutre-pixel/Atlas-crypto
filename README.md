# Atlas Crypto — Édition web (prototype enrichi)

Site statique gratuit : ouvrez `index.html` ou publiez le dossier sur GitHub Pages.

## Contenu
- 25 fiches synthétiques structurées en 5 parties, avec recherche et filtres.
- Laboratoire Bitcoin repris du prototype v0.5 (`laboratoire-bitcoin.html`).
- Visuel de couverture, navigation, quiz et lecture mobile.

## Important
Cette édition est une **version de fondation**, pas une encyclopédie de 25 chapitres exhaustifs. Les fiches sont des synthèses introductives ; les approfondissements, références spécifiques et vérifications éditoriales doivent encore être développés avant une publication présentée comme définitive. Les exercices sont des contrôles de méthode, pas des évaluations de maîtrise de chaque sujet.

Le laboratoire peut nécessiter HTTPS ou localhost pour certaines fonctions cryptographiques. Aucune donnée personnelle n'est collectée. Aucune donnée de marché en temps réel.

## Publication
Déposer les fichiers à la racine d'un dépôt GitHub public, puis activer Settings > Pages > Deploy from a branch > main / root. Ne pas confondre ce dépôt local avec une publication effective.
